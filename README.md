LeiloesTDSat
Sobre o Projeto
O LeiloesTDSat é uma aplicação desktop desenvolvida em Java com o objetivo de auxiliar no gerenciamento de uma casa de leilões. O sistema permite o cadastro e a listagem de produtos, possibilitando o armazenamento e a consulta das informações em um banco de dados.

O projeto foi desenvolvido como atividade prática de versionamento utilizando Git e GitHub, aplicando conceitos de controle de versão em um projeto de software.

Funcionalidades
Cadastro de produtos
Listagem de produtos cadastrados
Integração com banco de dados MySQL
Interface gráfica desenvolvida em Java
Tecnologias Utilizadas
Java
MySQL
Apache Ant
Git
GitHub
